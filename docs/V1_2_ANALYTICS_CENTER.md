# OnlyBeats v1.2 — Analytics Center, Phase 1

## Added

- Dedicated Analytics Center page
- Weekly report cards
- Prediction-type performance
- Team-by-team performance
- Conference performance
- Confidence-range calibration
- Cumulative season score trend
- Best type, team, and week summaries
- Analytics CSV export
- Views for Overview, Weekly, Teams, Conferences, and Confidence

## Data behavior

The Analytics Center reads the existing prediction journal. It does not generate picks, change scoring, alter confidence values, or modify archived data.

- Weekly report cards render

- Confidence calibration renders
- Analytics CSV downloads

- Season Archive still works
- Production checks still pass

# OnlyBeats v1.0 Release Candidate 1

## Focus

This release candidate emphasizes polish and release readiness rather than changing football data or prediction scoring.

## Added

- v1.0 release-candidate branding
- Alt+1 through Alt+9 navigation shortcuts
- Keyboard shortcut guide
- High-contrast preference
- Larger-text preference
- Improved visible keyboard focus
- Reduced-motion enforcement
- Final release-readiness checks
- Exportable release report
- Improved startup status sequence
- Release information inside Settings

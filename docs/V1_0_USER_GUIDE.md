# OnlyBeats v1.0 Quick User Guide

## GameDay workflow

1. Open Dashboard or Briefing.
2. Refresh the live provider.
3. Pin important games in Watch Center.
4. Open a matchup in Game Hub or Focus Mode.
5. Save predictions in Prediction Center.
6. Review performance in Prediction Intelligence.
7. Follow updates in Timeline.

## Keyboard shortcuts

## Local data protection

Settings includes:

- Back up local data
- Restore local data
- Export diagnostics and production reports
- Run final smoke and production checks

OnlyBeats stores user preferences, notes, predictions, futures, availability notes, timeline events, and pinned games locally.

# Stadium Data Attribution

The bundled stadium fallback was generated from the public
`stadiums-geocoded.csv` file in Geoff Boeing's
`gboeing/data-visualization` GitHub repository under the
`ncaa-football-stadiums` project.

The source dataset contains historic NCAA stadium metadata and
geocoded latitude/longitude values. OnlyBeats supplements it with
runtime alias matching and a cached geocoding fallback so newer,
renamed, or missing venues can still resolve.

Review the upstream repository's current licensing and attribution
information before redistributing OnlyBeats commercially.

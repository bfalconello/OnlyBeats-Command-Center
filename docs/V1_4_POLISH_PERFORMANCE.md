# OnlyBeats v1.4 — Polish & Performance, Phase 1

## Added

- Dedicated Performance Center
- Performance Mode
- Long-task monitoring
- Page render-budget warnings
- Startup and render summaries
- Performance report export
- Responsive layouts for medium and small windows
- Single-column phone-width preview behavior
- Session performance filters
- Performance Mode setting

## Performance Mode

Performance Mode reduces visual effects, disables expensive backdrop effects, hides decorative hero artwork, and enforces reduced motion.

## Unchanged

- Prediction scoring
- Predictions and futures
- Live provider behavior
- Season Archive
- Analytics calculations
- Backup and restore

## Regression checklist

- Performance appears in the sidebar
- Enable and disable Performance Mode
- Navigate through several pages
- Render metrics appear
- Export report works
- Responsive layout works at smaller widths
- Dashboard, Data Health, Analytics, Archive, and Prediction Center still open

# v0.15 — Prediction Intelligence, Phase 1

## Added

- Prediction review queue
- Context-readiness score
- Missing-reasoning checks
- Missing-line checks
- Availability concern checks
- Venue-weather shortcut checks
- Broadcast-context checks
- Confidence calibration gap
- Journal consistency summary
- Filters for All, Needs Review, Ready, Pending, and Graded
- Direct actions to edit predictions, open game details, and load venue weather

## Important

This release reviews the user's saved prediction journal. It does not generate picks, recommend wagers, estimate win probability, or change scoring rules.

# OnlyBeats v1.0 Release Candidate 2

RC2 improves startup visibility, page-render performance tracking, provider-state messaging, and recovery diagnostics.

## Added
- Online, cached, and offline provider banner
- One-click provider retry
- Page render timing
- Startup duration tracking
- RC2 readiness checks
- Exportable recovery snapshot
- Performance and recovery summary in Settings

## Unchanged
Prediction scoring, confidence behavior, odds, futures, local user data, and the score-provider flow remain unchanged.

# v0.12 — Intelligence Engine, Phase 1

## Added

- Game Priority Score
- Unified intelligence feed
- Recommended next action
- Smart prioritization based on:
  - Live status
  - Favorite teams
  - Ranked matchups
  - Close scores
  - Saved predictions
  - Manual availability notes
  - Upset signals
- Quick actions into:
  - Focus Mode
  - Prediction Center
  - Player Availability
  - Game Details
  - Watch Center

## Data integrity

The engine combines only information already present in OnlyBeats. It does not invent predictions, injuries, rankings, scores, or news.

## Regression checklist

- Intelligence page opens
- Refresh Intelligence works
- Priority cards appear
- Top recommendation works
- Focus action works
- Prediction action works
- Availability action works
- Details action works
- Pin action adds to Watch Center
- Prediction Center helper remains present

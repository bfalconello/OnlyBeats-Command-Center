# OnlyBeats v1.5 — Live Alert Center, Phase 1

## Added

- Dedicated Live Alert Center
- Alerts for:
  - Live games
  - Score changes
  - Lead changes
  - Ranked-team upset signals
  - Overtime
  - Final scores
  - Favorite-team activity
  - Player availability concerns
- Search
- Favorites-only and ranked-only filters
- Critical, warning, upset, lead-change, favorite, final, and availability views
- Pin/unpin alerts
- Read/unread controls
- Mark all read
- Mute/unmute
- Clear alert history
- Quick actions into games, teams, and Player Availability

## Data integrity

This release does not invent touchdowns, drives, injuries, or play-by-play. Alerts are generated only from data already present in OnlyBeats.

## Regression checklist

- Live Alerts appears in the sidebar
- Refresh Alerts works
- Filters work
- Search works
- Pin and read controls work
- Mute and unmute work
- Game and team actions open
- Alert history persists after restart
- Prediction Center, Analytics, Archive, Data Health, and Performance still open

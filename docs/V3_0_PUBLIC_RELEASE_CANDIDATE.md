# OnlyBeats v3.0 — Public Release Candidate

## Added

- Release Hub
- Branded v3.0 first-launch experience
- Required and optional release-readiness checks
- Installer verification checklist
- Backup and Command Mode verification
- Release channel preference
- Support-report export
- v3.0 release notes
- Distribution-boundary documentation
- Stable installer metadata for version 3.0.0

## Current release boundary

v3.0 can be built, installed, and shared for testing. The installer remains unsigned until a code-signing certificate is configured. Automatic update downloads and a hosted public download page remain disabled until their publishing services are connected.

## Installer

Expected output:

`dist/OnlyBeats-Setup-3.0.0.exe`

## Release-candidate checklist

- Complete first-run onboarding
- Select favorite teams
- Create and restore a test backup
- Enter and exit Saturday Command Mode twice
- Install the generated Windows installer
- Run all production checks
- Verify unavailable provider feeds remain labeled
- Export a support report
- Confirm both GitHub Windows workflows are green

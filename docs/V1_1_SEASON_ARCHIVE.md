# OnlyBeats v1.1 — Season Archive, Phase 1

## Added

- Dedicated Season Archive page
- Named weekly or custom snapshots
- Immutable copies of:
  - Games and scores
  - Predictions
  - Futures
  - Player-availability notes
  - Timeline events
  - Favorites
  - Quick notes
  - Season reflection
- Archived accuracy and score summaries
- Snapshot filters
- Individual archive export
- Complete archive collection export
- Archive import
- Snapshot deletion

## Data behavior

Saving or viewing an archive does not alter live scores, current predictions, scoring rules, or current local data. Imported archives are added to the archive collection only.

## Regression checklist

- Season Archive appears in the sidebar
- Save Current Snapshot works
- Snapshot details display
- Predictions and scores remain unchanged after saving
- Individual export works
- Export All works
- Import works
- Delete works
- Production checks still pass

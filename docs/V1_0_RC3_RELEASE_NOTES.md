# OnlyBeats v1.0 Release Candidate 3

## Focus

RC3 is the final regression-safety and local-data protection pass before v1.0 Final.

## Added

- Automatic startup smoke checks
- Render validation for every major page
- Prediction helper validation
- Local-data backup to JSON
- Validated local-data restore
- Final combined release report
- RC3 checklist inside Settings

## Unchanged

- Prediction scoring
- Confidence behavior
- Odds and futures
- Live score provider flow
- User data format
- Existing RC1 and RC2 polish

## Regression checklist

- App launches
- Settings shows the RC3 card
- Run RC3 Smoke Checks works
- Backup Local Data downloads JSON
- Restore Local Data accepts a valid backup
- Export Final Release Report downloads JSON
- Every major page opens
- Winner, Spread, and Over/Under still work
- Refresh controls remain functional

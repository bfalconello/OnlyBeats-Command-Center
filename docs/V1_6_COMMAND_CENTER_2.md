# OnlyBeats v1.6 — Command Center 2.0, Phase 1

## Added

- Dedicated Mission Control page
- Layout presets:
  - Balanced
  - Live
  - Predictions
  - Favorites
- Favorite-team command bar
- Live games, priority games, unread alerts, kickoffs, and pending predictions in one view
- Pop-out matchup windows
- Desktop notification permission and controls
- One-click access to Focus Mode, Game Hub, Watch Center, Alert Center, Analytics, Data Health, and Performance
- Saved Mission Control preferences

## Data behavior

Mission Control uses existing OnlyBeats data. It does not change predictions, scoring, providers, archives, analytics, or alerts.

## Regression checklist

- Mission Control appears in the sidebar
- Every layout preset works
- Favorite command bar can be hidden and shown
- Pop-out windows open
- Desktop notification permission works
- Refresh Mission Control works
- Focus and Game Hub buttons work
- Prediction review buttons work
- Production checks pass

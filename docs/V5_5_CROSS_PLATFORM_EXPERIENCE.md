# OnlyBeats v5.5 — Cross-Platform Experience

## Combined roadmap

This release combines the planned v5.1 through v5.3 work:

- Smarter cross-device synchronization
- Mobile Companion polish
- Coordinated live refresh and in-app alerts

## Added

- Cross-Platform Experience dashboard
- User-editable device names
- Local device registry
- Global cloud-sync status indicator
- Pending-queue visibility
- Configurable sync success and failure notices
- Local pre-sync recovery snapshots
- Snapshot restoration
- In-app notification center
- Coordinated automatic score, weather, ranking, and availability refresh
- Configurable live-refresh interval
- Manual live refresh
- Mobile bottom navigation
- Compact mobile-card mode
- Reduced-motion option
- Developer QA coverage
- Production readiness checks

## Firebase configuration warning

Back up `app/firebase-config.js` before applying the full package.
Restore it after copying v5.5 files so your existing Firebase project
remains connected.

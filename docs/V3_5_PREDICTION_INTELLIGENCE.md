# OnlyBeats v3.5 — Prediction Intelligence

## Added

- Dedicated Prediction Intelligence page
- Transparent prediction ranking
- Five-level intelligence grade
- Saved-confidence scoring
- Historical team performance context
- Historical conference performance context
- Ranking matchup context
- Weather-impact context
- Confidence and context warnings
- Strongest historical teams
- Strongest historical conferences
- Suggested combo from the user's own saved predictions
- Adjustable confidence, history sample, row count, and combo size
- Toggle controls for each scoring category

## Scoring boundary

Prediction Intelligence uses only the user's saved predictions,
locally graded history, rankings, weather, and game context.

It does not use:

- Odds
- Sportsbook data
- Wagering feeds
- Hidden AI
- Financial-return projections

## Installer

Expected output:

`dist/OnlyBeats-Setup-3.5.0.exe`

- Prediction Intelligence appears in the sidebar

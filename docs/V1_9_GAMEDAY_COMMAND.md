# OnlyBeats v1.9 — GameDay Command Center, Phase 1

## Added

- Dedicated GameDay Command page
- Time-window grouping:
  - Noon
  - Afternoon
  - Primetime
  - Late Night
- Game filters:
  - All
  - Live
  - Close
  - Ranked
  - Favorites
  - Predictions
- Layout presets:
  - Balanced
  - Close Games
  - Ranked Games
  - Predictions
  - Favorites
- Compact and expanded grids
- Prediction-team trailing signals
- High-confidence prediction-live signals
- Auto Focus for the highest-priority live game
- Focus Mode, Game Hub, and pop-out actions

## Data integrity

This release does not invent possession, red-zone status, play-by-play, or momentum. It uses only current scores, game state, rankings, favorites, saved predictions, and existing Smart Insight priority signals.

## Regression checklist

- GameDay Command appears in the sidebar
- Every preset works
- Every filter works
- Compact and expanded grids work
- Refresh GameDay works
- Focus Mode works
- Game Hub works
- Pop-out windows work
- Auto Focus can be enabled and disabled
- Production checks pass

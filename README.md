# OnlyBeats Command Center

> Your complete college football command center.

**Current version: v0.9.1 — Prediction Center Expansion**

OnlyBeats Command Center is a Windows desktop college-football companion featuring a live Saturday Wall, Team Hub, Intelligence Center, weather, alerts, customizable dashboards, centralized team metadata, and a personal Prediction Center.

## v0.9.1 highlights

- Winner, spread, and Over/Under prediction journal
- Unlimited positive numeric confidence values
- Automatic final-game grading
- Correct score equals the exact confidence entered
- Season analytics, streaks, confidence efficiency, achievements, and CSV export

## Run locally

1. Install the prerequisites in `INSTALL_WINDOWS.md`.
2. Run `RUN_DESKTOP.bat`.
3. Complete `TEST_CHECKLIST.md`.

See `docs/PROJECT_BIBLE.md`, `docs/ARCHITECTURE.md`, and `ROADMAP.md` for product and engineering direction.

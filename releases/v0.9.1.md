# OnlyBeats Command Center v0.9.1 — Prediction Center Expansion

## Added

- Optional Odds reference field for game predictions.
- Dedicated Futures workspace for season-long predictions.
- Built-in futures categories and custom outcomes.
- Unlimited positive numeric confidence for futures.
- Futures resolution: Pending, Correct, Incorrect, or Void, including quick resolution controls for locked preseason entries.
- Exact confidence scoring for correct futures.
- Season Lock for preserving preseason futures.
- Combined game/futures analytics and Season Yearbook reporting.
- CSV export now includes odds and futures records.

Odds are stored as reference text only and never calculate a financial payout.

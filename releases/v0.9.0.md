# OnlyBeats Command Center v0.9.0 — Prediction Intelligence

## Added

- Prediction Center with winner, spread, and Over/Under entries.
- Confidence accepts any positive numeric value, including decimals, with no fixed upper limit.
- Correct predictions earn a score equal to the exact confidence entered.
- Incorrect predictions earn zero.
- Configurable push scoring: full, half, or zero confidence.
- Automatic grading when linked games become final.
- Prediction journal notes, editing, deletion, and result filters.
- Season score, accuracy, confidence efficiency, streaks, pending count, and personal bests.
- Confidence-band analytics and achievement badges.
- CSV export for prediction history.
- Prediction summary dashboard widget.

## Data and privacy

Predictions are stored locally on the computer using application storage. No sportsbook connection, wager placement, or financial payout calculation is included.

## Upgrade

No SQLite migration is required. Existing v0.8.0 settings, favorites, dashboard layout, notes, and other local data remain compatible.

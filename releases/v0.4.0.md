# OnlyBeats Command Center 0.4.0 — Team Hub

## Added
- Clickable teams from the Saturday Wall game drawer.
- Searchable Team Hub directory populated from the live scoreboard.
- Team overview, current-slate schedule, snapshot statistics, and roster-ready tabs.
- Favorite controls inside every Team Hub.
- Team results in the Ctrl+K command palette.
- Responsive desktop and laptop Team Hub layouts.

## Data coverage
Team identity, logos, rankings, records, and current-slate games use the existing live scoreboard. Full-season rosters and advanced statistics remain provider-ready and do not display invented data.

## Database
No migration required.

# OnlyBeats Command Center v0.8.0 — Data Platform

## Added
- Shared team metadata platform loaded before the UI.
- Conference mapping for major FBS programs with safe FBS fallback.
- Stadium, city, state, timezone, team-color, and metadata-source fields.
- Stadium inference from the current scoreboard plus curated overrides.
- Team Hub now displays conference, stadium, location, timezone, colors, and metadata source.
- Developer Tools now reports data-platform coverage and provider health.
- All existing Saturday Wall, Team Hub, Intelligence, Weather, alerts, notes, themes, and dashboard personalization remain available.

## Data integrity
The platform uses live scoreboard identity data first, then applies limited curated metadata overrides. Unknown values are clearly labeled instead of guessed.

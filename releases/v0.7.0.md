# OnlyBeats Command Center v0.7.0 — Personal Command Center

## Added
- Customizable dashboard widget layout
- Drag-to-reorder dashboard cards
- Widget visibility controls and layout reset
- Quick Notes with automatic local saving
- Five professional themes: Midnight Gold, Stadium Green, Ice Blue, Classic Charcoal, and Light
- Comfortable and compact dashboard density options
- Improved startup-page preferences
- Expanded settings export containing dashboard layout and notes

## Data and compatibility
- No SQLite migration is required.
- Existing favorites, filters, alerts, and weather preferences are preserved.
- v0.6 settings are migrated automatically to the v0.7 settings key.
- Personalization data remains local to the current Windows profile.

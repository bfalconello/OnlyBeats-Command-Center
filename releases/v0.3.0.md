# OnlyBeats Command Center v0.3.0

## Saturday Wall

### Added
- Responsive Saturday Wall game grid.
- Live, Upcoming, Final, Top 25, and Favorites filters.
- Favorite matchups pinned ahead of other games.
- Persistent Saturday Wall search and filter preferences.
- Sliding game-details drawer.
- Automatic score refresh with 15, 30, 60 second, or Off settings.
- In-app score-change alerts and card highlighting while the app is open.
- Compact card mode and reduced-animation behavior.
- Updated Developer Tools diagnostics.

### Compatibility
- Existing favorites are preserved.
- Existing v0.2 settings are migrated to the v0.3 settings format.
- No SQLite migration is required.

### Verification status
- JavaScript syntax validated in the release workspace.
- Native Windows build must be verified locally or through GitHub Actions.

# Start Here — OnlyBeats Command Center 0.2.1

## Fastest test
1. Extract the complete ZIP.
2. Double-click `RUN_DESKTOP.bat`.
3. Wait for Rust to download and compile the new networking dependency. The first 0.2.1 build can take several minutes.
4. Open **Live Games**.
5. Select **Refresh now**.
6. Open **Developer Tools** to verify provider health.

## Browser preview
`PREVIEW_APP.bat` can preview the interface, but browser security or CORS rules may block the score request. The Tauri desktop build is the supported live-data path.

## Important
Do not delete 0.2.1 until all items in `TEST_CHECKLIST.md` pass.

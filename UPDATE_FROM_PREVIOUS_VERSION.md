# Update from v0.7.1 to v0.8.0

1. Keep the working v0.7.1 folder as a rollback copy.
2. Extract v0.8.0 into a separate folder.
3. Run `RUN_DESKTOP.bat`.
4. Complete `TEST_CHECKLIST.md`.
5. Copy v0.8.0 into the cloned GitHub repository, preserving the hidden `.git` folder.
6. Commit and push.

No database migration is required. Local preferences remain compatible.

# Update from v0.4.0 to v0.5.0

1. Keep the working v0.4.0 folder as a rollback copy.
2. Extract v0.5.0 into a new folder.
3. Run `RUN_DESKTOP.bat`.
4. Open Rankings to test Intelligence Center.
5. Open News to test Game Signals.
6. Complete `TEST_CHECKLIST.md`.

No SQLite migration is required. Local preferences and favorites use the same application data location.

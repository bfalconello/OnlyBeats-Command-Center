# Update from v0.9.0 to v0.9.1

1. Keep v0.9.0 as a rollback folder.
2. Extract v0.9.1 into a new folder.
3. Run `RUN_DESKTOP.bat` and complete `TEST_CHECKLIST.md`.
4. Copy only v0.9.1 contents into the cloned GitHub repository, preserving `.git`.
5. Commit and push.

Existing game predictions remain compatible. Odds and futures are added as optional local fields.

# Update from v0.6.0 to v0.7.1

1. Keep the working v0.6.0 folder as a rollback copy.
2. Extract v0.7.1 into a separate folder.
3. Run `RUN_DESKTOP.bat`.
4. Confirm existing favorites and settings appear.
5. Open Settings and choose a theme, dashboard density, and startup page.
6. Open Dashboard and arrange the widgets.
7. Complete `TEST_CHECKLIST.md` before replacing your previous release.

No database migration is required. Preferences are stored in the Windows user profile and migrate automatically.

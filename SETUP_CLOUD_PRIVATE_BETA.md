# OnlyBeats v5.0 Cloud and Mobile Private Beta Setup

1. Create a Firebase project and register a Web app.
2. Enable Authentication → Email/Password.
3. Create Cloud Firestore.
4. Paste the public web configuration into `app/firebase-config.js`.
5. Deploy the included `firestore.rules`.
6. Run the Windows app, open Cloud Sync Beta, and create your private account.
7. Deploy the `app` directory with Firebase Hosting for phone access.
8. On iPhone use Safari → Share → Add to Home Screen.
9. On Android use the browser's Install app option.
10. Keep local exports while testing offline edits and conflicts.
